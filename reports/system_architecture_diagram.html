TypeSafe Integration — 3 Primitives, 5 Patterns
PrimitiveQuestionExample AnswerUse in Our System
ChoiceOne of defined settask_type: pre_meeting_brief (prob 1.0, conf 1.00)Intent routing, answerability classification, model selection
NoulWhether condition holds — prob yesneeds_internal: 0.99, injection: 0.98Guardrail, verification, needs_internal/external, auth violation
ScoreDegree along ordered levelsrisk_level: 2.0/3.0 conf 1.00, strength: 0.0/4.0Risk scoring, citation strength, difficulty
Pattern 1 — Route and Fill Known Arguments
Request selects handler + typed params. Ask branch-specific questions up front, consume only relevant answers.
→ Our: task_type Choice → if pre_meeting_brief → ask needs_internal/external, else skip
→ Saves tokens, 150ms
Pattern 2 — Confidence-Gated Routing
Answer tells what, confidence tells whether to act. Use confidence as second axis.
→ Our: conf<0.6 → escalate to DeepSeek/DSPy, conf>=0.6 → use Jev directly
→ Live: 36/50 escalated, 14 saved
Pattern 3 — Verify and Escalate
Check specific claims against evidence, send uncertain/failing to person or reasoning model.
→ Our: Noul supported + contradiction + Score strength → BLOCK/HUMAN_REVIEW/PASS
→ R01: supported 0.01 contradiction 0.99 → BLOCK P1 100%
Pattern 4 — Composite Scoring
Break complex judgment into atomic scores, combine with weights in code. Changing weight need not rerun inference.
→ Our: privacy_risk, auth_violation, hallucination, conflict, missing_data → weighted → P0/P1
→ Weights change in code, no rerun

Why Code Owns Workflow — Engineering Poise
• Known rules, calculations, exact lookups, execution in code — not LLM
• Preserve stack and scope — add TypeSafe where semantic understanding helps
• Typed output guarantees interface, not truth — System One calibrated decisions, validate in domain
• Extra questions still use tokens — measure actual budgets, cost, latency
• Keep policy explicit and raw judgments reusable — weighted scores suit compensating preferences, "any serious violation" needs separate conditions

→ Our: Policy matrix deterministic 72 combos, memory isolation deterministic, registry no fallback deterministic — Jev adds semantic where deterministic fails (injection detection, citation check, intent routing)
