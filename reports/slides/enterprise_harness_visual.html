Why LangGraph not Chain
Stateful, not linear. AgentState persists across nodes, memory context, policy decisions, traces. Supports cycles (research → risk → research), conditional routing, human-in-loop REQUIRE_APPROVAL. Chain = stateless prompt → prompt. Graph = auditable state machine.
Decision: 6 Agents Only — Engineering Reason
Policy matrix = agents × tools. 6×12=72 combos testable. 20×30=600 combos untestable.

Bankers need 6 trusted agents with enforced contracts, not 20 clever agents with emergent behavior.

Each agent role maps to real desk: research (equity), compliance (legal), risk (risk), ops (operations), reporting (client coverage), supervisor (head).

Registry Spec — Engineering
class RegistryEntry(BaseModel):
  name: str # query_planner, decomposer
  version: str # semver 1.2.0
  artifact: Any # DSPy program, tool, prompt
  hash: str # sha256 of artifact
  lineage: list[str] # ['1.0.0 base','1.1.0 MIPRO']
  created_at: datetime
  provenance: dict # optimizer, dataset hash, metrics

class Registry:
  def register(self, name, version, artifact, lineage): ...
  def get(self, name, version) -> artifact
  def remove(self, name, version): ...
  def list_versions(self, name) -> list[str]

# Guarantees:
# 1. get(version) → executable, not stale pointer
# 2. remove() → behaviour change, not silent no-op
# 3. delete + get → ValueError, no fallback to latest

Replay Contract — Spec
class ReplayEvaluator:
  def replay(
    self,
    baseline_trace: Trace,
    candidate: Candidate
  ) -> ReplayResult:
    # 1. New trace_id, not reused
    new_trace_id = ulid()
    # 2. Actual execution, not cached/memoized
    result = candidate.execute(
      trace_id=new_trace_id
    )
    # 3. Diff detection
    diff = compare(
      baseline_trace.result,
      result.result
    )
    return ReplayResult(
      baseline_trace_id=baseline_trace.trace_id,
      candidate_trace_id=new_trace_id,
      diff=diff,
      is_same=diff.is_empty()
    )

# Guarantees:
# - new trace_id always
# - actual execution, no memoization
# - diff detected if behaviour changed
